2. Objectif principal du site

Le site doit positionner MDG GLOBAL HOLDINGS comme une entreprise internationale fiable spécialisée dans l’import-export, la logistique et la mise à disposition de véhicules, engins, équipements et produits provenant de différents marchés internationaux.

Le site ne doit pas être conçu comme une simple vitrine institutionnelle.

Il doit également fonctionner comme un catalogue commercial dynamique, permettant à l'entreprise de présenter régulièrement :

de nouveaux véhicules ;
de nouveaux engins ;
des motos ;
des équipements ;
des produits disponibles ;
des nouveautés ;
des gammes nouvellement proposées.

L’entreprise doit pouvoir enrichir elle-même le catalogue au fil du temps, sans devoir reconstruire le site à chaque ajout.

3. Concept central à retenir

Conçois le site autour de deux dimensions complémentaires :

A. Site institutionnel

Il doit présenter :

l’entreprise ;
son histoire et son positionnement ;
ses secteurs d’activité ;
ses valeurs ;
son expertise ;
sa capacité à accompagner ses clients à l’international ;
ses coordonnées ;
ses services d’import-export, logistique et transport.
B. Catalogue dynamique

Il doit permettre de publier régulièrement des produits et véhicules sous forme de fiches.

Chaque fiche peut comporter :

plusieurs photos ;
nom du produit ;
catégorie ;
marque ;
modèle ;
année, lorsque pertinent ;
caractéristiques techniques ;
description ;
disponibilité ;
localisation/origine lorsque pertinent ;
prix ou « Sur demande » ;
bouton de contact ;
bouton WhatsApp ;
possibilité de demander un devis ou des informations.

Le catalogue doit être pensé comme un système évolutif, et non comme une galerie d'images statique.

4. Fonctionnalité essentielle : catalogue dynamique

Propose une architecture permettant à l'entreprise d'ajouter facilement de nouveaux produits.

Imagine par exemple une interface d'administration permettant au responsable de :

afficher les nouveautés.

Le système doit permettre de publier régulièrement de nouveaux contenus sans intervention technique.

Propose une direction artistique correspondant à une entreprise :

10. Images et contenu visuel

Les images de véhicules, engins et produits constituent un élément commercial majeur.

Propose une stratégie permettant de mettre fortement en valeur les images.

Les photos doivent pouvoir être :

nombreuses ;
remplacées facilement ;
organisées par produit ;
affichées dans des galeries ;
optimisées pour mobile ;
utilisées dans les sections « nouveautés ».

Prévois une expérience de consultation particulièrement agréable sur smartphone.

11. Mobile First

Le site doit être conçu en priorité pour être excellent sur :

smartphone ;
tablette ;
ordinateur.

Une personne doit pouvoir découvrir un véhicule depuis son téléphone, consulter plusieurs photos et contacter immédiatement MDG GLOBAL HOLDINGS.

Les CTA importants doivent être facilement accessibles :

Demander un devis
WhatsApp
Appeler
Envoyer un message

12. Conversion commerciale

Ne conçois pas uniquement un beau site.

Réfléchis à la manière dont le site transforme un visiteur en prospect.

Pour chaque grande section, identifie les appels à l'action pertinents.

Par exemple :

Vous recherchez un véhicule ou un équipement spécifique ?
Contactez-nous pour connaître les disponibilités et obtenir une offre.

Prévois un parcours simple :

Découverte → Consultation du produit → Intérêt → Contact → Demande de devis

13. Architecture technique recommandée

Propose ensuite une architecture technique adaptée au besoin.

Compare brièvement plusieurs solutions possibles, par exemple :

WordPress + WooCommerce ou solution catalogue ;
Webflow + CMS ;
solution headless/CMS ;
développement personnalisé.

L'objectif n'est pas nécessairement de vendre des produits directement en ligne.

Le catalogue peut être un catalogue de présentation avec demande de devis, notamment lorsque les prix et disponibilités varient.

Recommande la solution la plus pertinente en fonction :

du budget ;
de la facilité de mise à jour ;
de l'autonomie du client ;
de la gestion des images ;
du nombre potentiel de produits ;
de l'évolutivité ;
des performances ;
de la maintenance.

16. Questions à résoudre avant la conception finale

Avant de finaliser l'architecture, identifie les informations manquantes qui devront être demandées au client.

Par exemple :

Quels pays sont principalement desservis ?
Quels sont les marchés d'approvisionnement ?
Les produits sont-ils vendus uniquement au Burkina Faso ou dans plusieurs pays ?
Les prix seront-ils affichés ?
Les produits sont-ils disponibles immédiatement ou principalement sur commande ?
Quels moyens de paiement sont acceptés ?
Le client souhaite-t-il recevoir les demandes via WhatsApp ?
Qui administrera le catalogue ?
Combien de nouveaux produits sont ajoutés chaque mois ?
Le site devra-t-il être multilingue ?
Le client possède-t-il déjà un logo et une charte graphique ?
Dispose-t-il de photos professionnelles ?
Souhaite-t-il vendre directement en ligne ou uniquement recevoir des demandes de devis ?
Souhaite-t-il afficher les stocks/disponibilités ?
Souhaite-t-il publier des actualités régulièrement ?
